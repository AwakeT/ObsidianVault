
## 1. 一句话定位

DINO-GeoSemMap 是一个**只吃单帧 RGB、一次前向同时输出 深度/检测/分割/房间 四类感知结果**的统一感知模型。它**不建图、不预测位姿**——建图（GSM 合成）和位姿都在下游，由它的感知输出 + SLAM 位姿汇合完成。

---

## 2. 模型输入

|        | 内容           | 说明                                |
| ------ | ------------ | --------------------------------- |
| **必需** | `RGB_t` 单帧图像 | 模型唯一的网络输入（统一去畸变针孔图，工作分辨率 896×504） |

> 关键：**网络只看 RGB**。相机参数、位姿都只是前/后处理的元数据，不参与训练，也不进网络结构 → 换相机/换 SLAM 不用重训模型。

---

## 3. 模型输出（单帧四类）

```text
Y_t = {
  depth:   { depth_map[H×W], confidence[H×W], valid_mask[H×W] },   # 每帧 dense 米制深度
  objects: [ { box_2d, objectness, label(Top-50), score,
               instance_mask[bbox内], mask_score } ],               # 检测框 + 框内二值 mask
  room:    { room_type, room_confidence, room_logits[N] }           # 当前帧房间类型
}
```

| 输出  | 内容                     | 频率          |
| --- | ---------------------- | ----------- |
| 深度  | 全图稠密米制深度               | 每帧（10–20Hz） |
| 检测  | 家居 Top-50 物品 2D 框 + 类别 | 关键帧（1–5Hz）  |
| 分割  | 框内前景/背景二值 mask         | 关键帧         |
| 房间  | 帧级房间类型（软标签可多标签）        | 关键帧         |

**下游 GSM 合成**（不在模型内）：
- 物体定位：`框 + mask + 深度 + SLAM 位姿` → 反投影解算物体 **3D 世界坐标** → 写入语义地图；
- 房间分区：`门检测 + 深度/自由空间 + 帧级房间类型` → 几何分区(分水岭/图割,门处断开) + 区域内类型投票 → **房间实例 + 边界 + 类型**（详见 §4/§5）。

---

## 4. 与原先 ASM 地图的区别

**原先 ASM（几何分区 + 在线 VLM 房间分类路线）**：从占据栅格做几何分区（分水岭/距离变换 + 启发式合并），对每个区域采前后左右 4 张图调**在线 VLM** 分类房间，物体由单独检测器 + 深度组装成 3D 语义——前端多模型拼接、房间标注在线进行。

| 维度       | 原先 ASM 地图                        | DINO-GeoSemMap                                                           |
| -------- | -------------------------------- | ------------------------------------------------------------------------ |
| **房间来源** | 几何分区 + 逐区域**在线 VLM**（4 方向图调 API） | 模型**内置 Room Head**，帧级直接分类，无在线 VLM                                        |
| **房间分区** | 纯几何分区（**走廊/狭长区不稳**，跨场景需调参）         | 下游 GSM 用**门检测 + 自由空间 + 帧级类型投票**分区（门处断开，边界更稳）；Room Head 提供帧级类型先验 |
| **物体**   | 单独检测器，落到 2D 区域                   | 检测+分割与深度**同一 backbone 一次前向**出                                            |
| **模型形态** | 多模型拼接（分区/VLM/检测/深度各一套）           | **单模型**：冻结 DINOv2 + 4 独立 head 共享一次 forward                               |
| **深度**   | 单独立体/深度模型                        | 内置 DPT Depth Head，米制、可每帧高频                                               |
| **在线成本** | 每区域多次 VLM API 调用（慢/贵/网络依赖）       | 只需要一次前向就可以得到所有结果                                                         |
| **迭代**   | 改一处牵动整条流水线                       | 各 head **完全解耦**，单独重训不回归其他                                                |

---

## 5. 核心优势

1. **统一、共享、省算力**：一个冻结 backbone 一次前向出四类结果，不再多模型拼接、不重复跑骨干；端侧实时（深度每帧、其余关键帧）。
2. **房间标注离线化**：Room Head 帧级直接给房间类型（过渡区软标签），免去逐区域调在线 VLM 4 方向图的慢/贵/网络依赖；房间分区在下游 GSM 由**门检测 + 自由空间 + 帧级类型投票**完成，门处断开使边界更稳。
3. **解耦可独立迭代**：四个 head 互不影响，哪个效果差只重训哪个，工程上稳。
4. **相机/位姿无关**：网络只吃 RGB，内参/位姿仅作元数据 → 换相机、换 SLAM 不用重训。

---

> 一句话总结：**DINO-GeoSemMap 用单一冻结 backbone 一次前向输出深度/检测/分割/房间四类感知，配 SLAM 位姿在下游合成物体级 3D 语义地图，房间分区由门驱动几何方法 + 帧级类型投票完成——相比原先多模型拼接、逐区域在线 VLM 标注的方案，感知更快、流程更稳、算力更省、各 head 可独立迭代。**
