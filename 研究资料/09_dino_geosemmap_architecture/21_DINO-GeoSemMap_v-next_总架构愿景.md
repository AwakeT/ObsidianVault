## 0. 文档定位与产物边界

本文是 **DINO-GeoSemMap 下一代（v-next）的总架构愿景**，目的是把方向钉在墙上，不是某一个模块的可实现方案。

- **范围内**：整体架构、模块清单、依赖与分期路线图、对下游契约的影响、风险与开放问题。

## 1. 背景：为什么要做 v-next

### 1.1 当前 DSM 的成绩与墙

当前 DSM（见 [[07_DINO-GeoSemMap_架构设计]]）= **冻结 DINOv2 + 四个解耦头（深度/检测/分割/房间）**，单帧 RGB 一次前向出四类感知，不建图、不预测位姿，位姿与建图都在下游（SLAM + GSM 合成）。这套设计的工程优点很实在：相机/位姿无关、各头独立迭代、四头共享 backbone 一次前向（[[16_DINO-GeoSemMap_冻结DINOv2检测头优化方法总结]] §9：18.8ms / 53FPS）。

但检测头 E 系列已系统性证明了**三堵墙**（[[16_DINO-GeoSemMap_冻结DINOv2检测头优化方法总结]] §5、[[20_DINO-GeoSemMap_四头Loss设置与下一阶段优化]] §5）：损失级杠杆到顶，瓶颈钉死在**冻结 patch-14 特征本身**（FP_loc 42%、小物体 0.737 容量墙），结论是"下一阶段必须从调 loss 转向动特征 / 动分辨率"。这个结论对共享同一冻结基座的其余三头大概率同样成立。

### 1.2 Cosmos3 给出的对照与启发

[[Cosmos3]]（NVIDIA, 2026）用单一 Mixture-of-Transformers 双塔（reasoner + generator），统一五模态的理解与生成，把 VLM、视频生成、世界模拟、世界-动作模型纳入同一框架。它与当前 DSM 几乎每条设计哲学都相反：训练骨干 vs 冻结、统一 vs 解耦、生成 vs 判别、视频+动作 vs 单帧、基础模型规模 vs 小头。

v-next 不照搬 Cosmos3，而是**有选择地吸收**：

- **双塔/混合路径思想** → DSM 的"双干 + 联合注意力"（专长流 + 联合注意力，同时也是你们既有"共享基座 + 私有 delta"直觉的推广）。
- **位姿的 SE(3)+6D 相对表示** → 给位姿头当输出格式（但 DSM 把它当**感知估计**，而非 Cosmos3 里消费的**动作 token**）。
- **绝对时间轴对齐** → 帧 buffer / 时序对齐的参考。
- **明确不吸收**：动作模态与 policy/前向-逆向动力学 —— **动作整条留给下游 VLN/VLA**。

### 1.3 v-next 要补的能力缺口

在"持续聚焦感知"的前提下，把当前缺的三类能力收进来：**当前场景物品的感知（已有，需升级）+ 时序推理 + 部分（去动作的）预测 + 自身相对位姿感知**。

## 2. 愿景一句话 + 设计决策摘要

> **DSM-v-next = （半冻结、特征松动的）感知主干 + 共享帧 buffer 的时序注意力，之上挂：四个感知头 + 三类被动预测（nowcast / amodal / 动态外推）+ 一个相对位姿头（VO 前端，深度锚定尺度，内参鲁棒）；动作给 VLN，薄几何后端做全局一致性。具体落地为双干（语义干 + 几何/时序干）+ 联合注意力。**

本愿景已拍板的关键决策：

| 决策点 | 结论 |
|---|---|
| 总范围 | 持续聚焦**感知**；动作输出整条交给下游 VLN/VLA |
| 预测的定义 | **去动作的被动预测**：场景状态推断/补全 + 动态体短时外推；**不做**依赖动作的第一人称未来 rollout（那个留给 VLN） |
| 位姿 | 收进 DSM，但作为**感知输出**（相对位姿/VO），不是动作 |
| 脚手架去到哪 | **只吸 VO 前端**，保留**薄几何后端**（pose-graph + 回环）做全局一致；不追 full neural SLAM |
| 内参 | 尽量**跨相机通用**：模型自估内参 / 内参等变设计，不绑定固定标定 |
| 实时红线 | 愿景阶段**暂时放开**，先追能力上限（空间智能）；实时/部署作为后续工程压缩（TensorRT/int8/蒸馏）问题 |
| 集成哲学 | **方案 C：双干 + 联合注意力**（语义干复用 DINOv2，几何/时序干用视频/多视预训练） |

## 3. 总体架构与数据流

详见配图 `DINO-GeoSemMap_v-next_双干架构.drawio`。

```text
                     最近 N 帧滚动 buffer(无位姿,纯连续帧)
                     RGB_{t-N+1 … t}
                           │
        ┌──────────────────┴───────────────────┐
        ▼                                       ▼
  语义干 Semantic Trunk                   几何/时序干 Geo-Temporal Trunk
  DINOv2 ViT (frozen + LoRA)             视频/多视预训练 (VGGT/DUSt3R 族)
  逐帧 patch 特征                          帧 buffer 上的时空特征 + 原生几何
        │                                       │
        └────────── 联合注意力 Joint Attention ──┘
            (几何干→语义干: 空间/多视一致性先验
             语义干→几何干: 物体/类别先验)
                           │
   ┌──────────────┬────────┴───┬──────────────┬─────────────┐
   ▼              ▼            ▼              ▼             ▼
 语义头(复用)    深度头(几何干, 位姿头(新)     预测头 ×3(新)
 Det/Mask/Room  米制)        Rel-Pose       Nowcast/Amodal/Dynamic
                            ΔT: SE(3)+6D
                            深度锚尺度/内参鲁棒
                           │
                           ▼
                   网络输出 Y_t(现有契约的超集)
                           │
                           ▼
              薄几何后端(网络外):pose-graph + 回环 → 全局一致
                           │
                           ▼
            下游 GSM/ASM(现在可吃 DSM 自产位姿) → VLN/VLA(动作在此)
```

**核心要点**：

1. **两个专长干各司其职**：语义干 = DINOv2（冻结+LoRA），det/mask/room 基本复用 E 系列成果；几何/时序干 = 视频/多视预训练，原生出位姿与多视一致的深度。
2. **帧 buffer 无位姿**：短滚动窗口，跨帧对应**由注意力隐式学**（不喂光流、不喂位姿），保住"换相机/SLAM 不强依赖外部标定"的精神。
3. **联合注意力是方案 C 的灵魂**：双向 cross-attention 让两干互补——几何干把空间一致性灌给语义（治 FP_loc / 小物体），语义干把物体先验灌给几何（治无纹理区位姿漂移）。
4. **前端学、后端薄**：全局一致性留给网络外的 pose-graph + 回环。
5. **输出向后兼容**：`Y_t` 是现有 depth/objects/room 的**超集**，下游 GSM 零回归且更肥。

## 5. 关键设计点详解

### 5.1 双干与联合注意力

两干参数独立、各用各自最强的数据预训练；通过帧 buffer 上的 cross-attention 互通。开放问题：联合注意力**对称还是非对称**。Cosmos3 是非对称的（AR token 永不被 DM 更新，保持因果完整）；DSM 里可类比为"语义干是否允许被几何干更新"——保护语义干的成熟能力 vs 让几何一致性反哺语义，需在 P1 实验定夺。

### 5.2 位姿作为感知（不是动作）

- **表示**：相对 SE(3) 伪量 ΔT_t = T_{t-1}⁻¹ T_t，旋转用 6D 表示（预测后 SVD 转回 SO(3)），格式直接抄 [[Cosmos3]]。
- **尺度**：单目相对位姿尺度模糊；DSM 有**米制深度头**，可直接锚定位姿尺度——这是 DSM 做自定位相对纯 RGB VO 的关键优势。
- **职责边界**：只做 VO 前端（帧间相对位姿 + 局部几何），全局漂移/回环交给 M6 薄后端。

### 5.3 内参跨相机通用

为保住"换相机不重训"的精神，位姿/几何不绑定固定内参：走**模型自估内参**或**内参等变设计**（参考 VGGT / UniDepth 等"不依赖给定内参"的做法）。这是 P0/P2 的一个硬验证点——自估内参精度不够会污染位姿与深度。

### 5.4 被动预测三头（去动作的预测定义）

去掉动作后，家居场景"未来"的大部分变化来自 ego-motion（本身是动作），那一类**第一人称未来画面预测是病态的，留给 VLN**。DSM 只做**良定义、与动作无关**的三类：

- **Nowcast 稳化**：用过去几帧把当前帧感知"算稳"（深度不抖、检测不跳）。最易、价值最高，**最先做**。
- **Amodal / 遮挡补全**：空间预测——推断当前物体被挡住的完整范围、被遮挡空间。
- **动态体短时外推**：人/宠物/门的 1–2 秒轨迹，不依赖机器人动作，服务安全导航。

### 5.5 前端学 / 后端薄

"去掉定位脚手架"的现实目标不是消灭，而是**把脚手架最重的前端（VO + 深度 + 语义 + 时序）吸进 DSM，把外部脚手架缩成一根薄后端**（pose-graph + 回环），而非一整套外挂 SLAM。Full neural SLAM 属研究前沿，不在本愿景承诺内。

## 6. 分期路线图与可证伪闸门

沿用 E 系列"先诊断再下药"的方法论：**每期一个可证伪闸门，不过闸不堆复杂度**；每加一个模块先做一次"特征是不是瓶颈"的可分性诊断（类比 `scripts/diag_det_obj_sep.py`）。

```text
P0 地基  ── M1 几何干选型接入 + M2 语义干松动
   闸门: 几何干在家居数据上直出的 pose/depth 是否"可用"(对比外部 SLAM/GT);
         LoRA 松动是否真的抬过 E 系列那堵墙(FP_loc/小物体诊断复用 diag_det_*)
   └─ 不过闸 → 换几何干 / 调松动深度, 不往上堆

P1 融合  ── M3 帧 buffer + 联合注意力
   闸门: 双干联合 vs 单干基线, 语义指标(FP_loc/小物体)与几何一致性是否都涨?
         若不涨, 联合注意力没挣回成本, 砍回单干

P2 位姿  ── M4 相对位姿头(VO 前端)
   闸门: 一段轨迹的 VO 漂移 vs 外部 SLAM; 能否替代 SLAM 位姿供下游局部 3D?

P3 预测  ── M5 三头(nowcast → amodal → dynamic, 由易到难逐个上)
   闸门: 每头独立验收(稳化看跨帧抖动↓; amodal 看遮挡 IoU; 动态看短时轨迹误差)

P4 全局  ── M6 薄后端(pose-graph + 回环, 吃 M4 位姿)
   闸门: 长轨迹全局地图一致性; 脚手架是否真的缩到"薄"

(M7 数据线横切 P0–P4: 单帧 → 带位姿/带 tracking 视频, 与各期同步铺)
```

**P0 是整条路线的成败前提**：几何干选型不过闸，后面全部悬空。

## 7. 输出契约变化与下游影响

`Y_t` 在现有 depth / objects / room 基础上扩为超集：

```text
Y_t = {
  depth:   { depth_map, confidence, valid_mask },          # 现有, 米制(几何干精修)
  objects: [ { box_2d, label, score,
               instance_mask, mask_score,
               instance_id,          # 新: 跨帧物体恒存 ID
               amodal_mask, occluded,# 新: 完整范围 + 遮挡标志
               dynamic, motion_vec } ], # 新: 动态标志 + 短时运动
  room:    { room_type, room_confidence, room_logits },    # 现有
  pose:    { delta_T(SE3, 6D), pose_conf, intrinsics? }    # 新: 相对位姿(+自估内参)
}
```

对下游：

- **GSM/ASM 零回归**：旧字段不变，新字段是增量；物体级 3D 语义地图的输入更肥（amodal + instance_id 让多帧关联更稳）。
- **位姿来源切换**：下游现在可吃 DSM 自产位姿（经 M6 薄后端全局化），逐步降低对外部 SLAM 的依赖。
- **代价**：内参从"纯元数据"变为"模型自估/需关注"——跨相机通用性靠自估精度兜底（见 §5.3）。

## 8. 风险与开放问题

| 类别 | 风险 / 开放问题 | 应对 / 待定 |
|---|---|---|
| 几何干语义弱 | VGGT/DUSt3R 族几何强但语义弱，检测/房间可能退 | 双干正为此设计；语义头仍骑语义干，靠联合注意力补几何 |
| 自估内参 | 内参估不准会污染位姿/深度 | P0/P2 硬验证点；不达标则退回"内参作为已知输入" |
| 无位姿帧 buffer | 大运动 / 低纹理下跨帧对应可能失败 | 注意力隐式对应 vs 引入轻量几何先验，P1 评估 |
| VO 漂移 | 即便有薄后端，长轨迹仍可能累积 | 限定前端职责 + 后端 pose-graph/回环；不承诺 full SLAM |
| 数据稀缺 | 带位姿+tracking 的家居视频稀缺 | 仿真(Habitat/合成) + 真实混合；M7 横切铺设 |
| 训练复杂度 | 双干 + 多头联合训练不稳 | 分阶段冻结/解冻课程；按 P0–P4 增量上 |
| 联合注意力方向 | 语义干是否该被几何干更新（对称 vs 非对称） | P1 实验定夺（§5.1） |
| 监督来源 | amodal / dynamic 的标注从哪来 | 待 P3 子项专门设计（伪标签 / 仿真 GT） |
| 算力 | 双 backbone 翻倍 | 愿景阶段接受；落地阶段做压缩（蒸馏/量化/裁剪边端版） |

## 9. 与当前版本的关系（交易了什么）

v-next 是**有意识地用工程通用性换端到端的空间理解**：

- **保留**：感知聚焦、各头可独立迭代（双干内仍是多头）、四头输出向后兼容、下游 GSM/ASM 流程。
- **交易掉**：纯冻结基座（→ 半冻结/双干）、"网络只看 RGB / 内参位姿仅元数据"（→ 位姿成为输出、内参需自估）、纯单帧（→ 短时序 buffer）、边端实时的硬保证（→ 愿景阶段放开，落地再压缩）。

这个交易是否值，取决于 P0 闸门：几何干能否在家居数据上真的砸穿那堵特征墙。**先验证地基，再谈上层。**
