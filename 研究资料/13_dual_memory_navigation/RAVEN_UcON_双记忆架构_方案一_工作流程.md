# 双记忆家居导航系统 · 工作流程说明

> 方案一 · v0.3　|　感知情景记忆 **M1**（升级自 RAVEN）+ 结构化习惯记忆 **M2**（本文新增）
> 对应架构图：[RAVEN_UcON_双记忆架构_方案一.drawio](RAVEN_UcON_双记忆架构_方案一.drawio)

---

## 0. 一句话概览

感知流先经**在线关键帧抽取**写入**情景记忆 M1**（只记客观事实）；**习惯获取**阶段对 M1 做跨 episode 检索 → 检测兜底 → 聚合 → VLM 归纳，蒸馏出**结构化习惯 M2**（提炼规律）；**动态维护**持续强化 / 衰减 / 剪枝 M2；**在线找物**时当前观测**同时查 M2（习惯先验）与 M1（情景证据）**，融合进 VLM planner 决策，执行产生的新观测**回流 M1**——形成 **感知 → 获取 → 维护 → 利用** 的持续优化闭环。

**核心设计原则：职责隔离。** M1 存**确切事实**，M2 存**提炼习惯**；M2 通过 `support_refs` 指回 M1 证据，不复制事实。

---

## 1. 记忆层设计

| | **M1 · 情景记忆 Episodic** | **M2 · 习惯记忆 Habit** |
|---|---|---|
| 定位 | 确切事实层（客观观测） | 提炼规律层（★本文新增） |
| 内容 | 几何 pose · 时间 t · eid · z/o 引用；③检测证据（object 实例 / bbox / 共现物体） | `(object, relation, landmark, scene, 时段, conf)` + `support_refs` |
| 原则 | 只记客观观测，**不存**关系 / 习惯 | 只存提炼习惯，事实**指回** M1 不复制 |
| 来源 | RAVEN（情景 / 感知） | 本文 acquisition（UcON 所缺环节） |

**M1 存储示例：**
```json
{
  "eid": "e27", "frame_id": "f084",
  "time": "2026-07-06 22:44:12",
  "pose": [2.1, -1.4, 0.0],
  "scene": "bedroom",
  "detections": [ {"object":"book", "bbox":[...], "det_conf":0.91} ],
  "cooccur": ["bed", "lamp"],
  "z_ref": "vec_8831",
  "image_ref": "m1/e27/f084.jpg"
}
```

**M2 存储示例：**
```json
{
  "habit_id": "h_book_bed_night",
  "habit": "The user reads books in bed before sleeping.",
  "object": "book", "relation": "onTop", "landmark": "bed",
  "scene": "bedroom", "time_context": "before_sleep",
  "conf": 0.87, "support_count": 12,
  "support_refs": ["e12:f031", "e19:f052", "e27:f084"],
  "last_confirmed": "2026-07-06"
}
```

## 2. 工作流程（四阶段闭环）

### 阶段一 · 感知前端 Perception（写入 M1）

持续采集 egocentric RGB，**不做检测**，仅抽关键帧写入 M1。

1. **P1 采集**：探索 / 日常服务持续采集 egocentric RGB 帧流。
2. **P2 编码**：多模态编码器（图文对齐 / CLIP 类）→ 整帧向量 `z`（图文共享嵌入空间）。
3. **★ KF 在线关键帧抽取**（采集时实时）：
   - 持续计算 `z` 相似度曲线 + pose 辅助消歧；
   - **双采样**：平稳段代表帧 + 场景切换边界帧；
   - **仅关键帧的原图 `o` 落盘**，而 `z` 仍全量保真。
4. **① 写入 M1**：`z`（全量）· `o`（仅关键帧）· pose `p` · 时间 `t` · `eid`。

> 关键取舍：`z` 全量保真保证检索召回，`o` 仅关键帧节省存储，检测**延迟**到获取阶段再做。

### 阶段二 · 习惯获取 Habit Acquisition（M1 → M2）

离线 / 空闲时对 M1 做跨 episode 挖掘，蒸馏习惯。**粗筛用语义（高召回可粗）→ 精判用检测器（兜底补精度）。**

- **② 粗筛（跨 episode 语义检索）**：以文 / 以图 / 经 M2 桥接查 M1 → 召回候选帧（高召回，精度交 ③）。
- **③ 精判（实例级）**：候选帧原图 → 检测器 → `object`、`bbox`、共现物体（防漏小物品）。
  - **★ ③检测证据即时回写 M1**（延迟检测在此兑现，**不进 M2**，不等任务结束）。
- **④ 聚合（跨 episode）**：统计 `(relation, landmark, time)` → 置信度 `conf`。
- **⑤ 归纳**：代表帧 → VLM → 结构化习惯元组 → 写入 M2。

### 阶段三 · 动态维护 Maintenance（★ 维护 M2）

由新情景证据触发，对抗物体挪位、保持习惯新鲜：

| 触发条件 | 动作 |
|---|---|
| 新证据复现 | 强化（↑ conf） |
| 久未复现 | 衰减（↓ conf） |
| 位置变化 | 剪枝 / 改写 |

### 阶段四 · 在线找物 Retrieval-Fusion + Planning（利用 M1 + M2）

当前观测**同时查两套记忆**，融合决策：

1. **R1 当前观测**：目标 `o` → 检测 `o′`/`bbox` → 编码 `z′`。
2. **R2 查习惯记忆 M2**：取目标 `o` 的 `(relation, landmark, time)` 先验 + 间接地标习惯，按 `conf` 加权（"`o` 一般在哪"）。
3. **R3 查情景记忆 M1**（agentic 迭代）：见过 `o`？地标在哪个位姿？text / time / position / image 检索（"是否真见过 `o`/地标位姿"）。
4. **R4 融合**：当前观测 + 习惯先验 + 情景证据 → prompt → VLN planner（证据不足则**迭代检索**）。
5. **R5 规划执行**：plan → 低层规划器 → 动作（MoveAhead / Rotate / Open / Done）。
6. **★ 闭环回流**：每步执行 / 检测 → **即时回流 M1**（不等任务结束）。

---

## 3. 检索对齐机制（★ z 只有语义向量，如何按目标查）

- **前提**：`z` 来自图文对齐编码器（CLIP 类）→ 图文共享嵌入空间。
- **查询三入口**：以文搜图 / 以图搜图 / 经 M2 桥接（landmark 回检）。
- **粗召回分工**：场景级 `z` 只做粗召回；物体级精度由 ③ 检测器兜底。
- **小物体防漏**：放宽 top-k / 用 M2 先验先缩范围。

## 4. 数据流闭环总览

```
感知 ──① 写──▶ [M1 情景记忆] ──② 检索──▶ ③ 检测 ──④ 聚合──▶ ⑤ 归纳 ──▶ [M2 习惯记忆]
  ▲                  ▲   ▲                │                                    │
  │                  │   └── ③证据即时回写 M1                                  │
  │                  │                                              动态维护 ↕ (强化/衰减/剪枝)
  │            在线找物：R3 查 M1 ◀──┐        ┌──▶ R2 查 M2
  │                                 └── R4 融合 ──┘ → R5 规划执行 → 动作
  └────────────────── ★ 执行新观测即时回流 M1（紫虚线闭环）─────────────────────┘
```

## 5. 相对基线的关键增量

| 环节 | 来源 | 增量说明 |
|---|---|---|
| 情景记忆 M1 | RAVEN | 保留感知 / 情景层 |
| 在线关键帧抽取 | ★ 本文 | 采集时 z 相似度 + pose 双采样，延迟检测 |
| 习惯记忆 M2 + 获取 / 维护 | ★ 本文 | 补齐 **UcON 缺失的 acquisition**：从事实蒸馏结构化习惯并持续维护 |
| 在线找物决策 | UcON 升级 | 由"仅情景检索"升级为"**习惯先验 + 情景证据**双查融合" |

> **一句话定位**：在 RAVEN 的情景记忆之上，新增可获取、可维护的**结构化习惯记忆**，并让在线找物同时利用"长期习惯（o 通常在哪）"与"当前情景证据（是否真见过 o）"，形成持续自优化的双记忆闭环。
