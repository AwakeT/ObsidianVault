## 0. 方法结论

采用：

> **分阶段、解耦式、可靠性门控的多教师因果点图蒸馏。** 每个样本只有一个米制尺度锚；Pi3X 只提供 `local_points`、`world_points` 与 point confidence；学生预测对应的 local/world point map，再由统一的 confidence-weighted SE(3) SVD/Procrustes 确定性求 camera pose。当前不使用 LOGOPlanner/NavDP 的规划部分，也不把 direct pose head 或 pose token 作为正式输出来源。

方法主线：

```text
S0 目标域教师审计
  → S1 metric depth + local-point KD
  → S2 causal world-point + first-frame gauge KD
  → S3 learned point confidence + differentiable weighted SE(3) registration
  → S4 pose-from-points + reprojection + multi-span/cycle + overlap-window stitching
  → S5 bounded causal state、退化检测与 lost/reset
  → S6 量化、延迟与真机持续运行验证
```

明确不采用：

- 多个深度教师直接平均或同时施加等权 meter loss；
- Pi3X 未对齐尺度的 depth、local/world point；
- 未处理 gauge 的 absolute `c2w` 直接回归；
- 不同网络 raw feature 的逐通道 MSE；
- 对因果 pose/state 施加任意帧排列不变性；
- 使用未来帧的 full-clip 标签作为正式训练监督；
- 把 pixel confidence、point confidence 和由 solver 诊断派生的 frame pose covariance 混为一个字段；
- 让 direct pose head 在 point solver 失败时接管正式 `T_frontend`；
- 把 pose token、LOGOPlanner/NavDP 消费或规划指标设为当前方法成立的必要条件；
- 复制旧方案固定的 `0.5 feature + 0.3 pose + 0.2 depth` 权重；
- 一开始同时打开全部 loss、同时更换 teacher/backbone/head/data。

## 1. 监督角色与优先级

| 角色 | 提供的监督 | 方法侧约束 |
|---|---|---|
| `primary_metric` | metric depth、窗口米制尺度 | 每个样本唯一；低优先级来源不得覆盖 |
| `relative_shape` | SSI/ordinal depth、gradient、normal、boundary | 必须去除绝对尺度，不产生第二套 meter target |
| `pointmap_vo` | local/world point、point confidence、跨视一致性 | 点图必须使用主尺度和统一 gauge；camera pose 只由固定 weighted SE(3) solver 产生 |
| `feature_privileged` | token/query/relation | 默认关闭；只在 point-map output-only 基线上单独消融；不得成为正式 pose 来源 |

尺度优先级：

```text
metric GT
> calibrated RGB-D/LiDAR
> 目标域校准的单目 metric teacher
> 未校准单目 metric teacher
> Pi3X approximate metric
> metric_valid=false
```

GT/传感器有效像素始终优先；伪标签只补无标签样本、无效区或提供额外结构。

当前 Pi3X 数据管线只读取 `local_points`、`world_points` 和 confidence；其直接 camera pose、ray、CameraHead token、pose token 或内部 feature 均不缓存、不进入训练主链。所有 Pi3X 关系监督也只能由这三项已登记输出派生。

## 2. 坐标、尺度和 gauge 契约

### 2.1 位姿方向

禁止使用无方向下标的 `T`。统一定义：

- `T^front_{w←c,t}`：当前 segment 的前端相机到世界变换；
- `T_global_c2w`：后端优化结果；
- 相对位姿：

$$
\Delta T_{c_i\leftarrow c_j}
=(T_{w\leftarrow c,i})^{-1}T_{w\leftarrow c,j}.
$$

所有 teacher cache、loss、评测和部署接口都使用同一约定。合成单位变换必须覆盖：纯 X/Z 平移、正负 yaw、纯旋转和静止帧。

### 2.2 Pi3X 窗口尺度

在可信重叠区域 $\Omega$ 中，使用 GT、标定传感器或唯一 `primary_metric` 对 Pi3X 求窗口尺度：

$$
\log s^*=\operatorname{weighted\ median}_{(t,i)\in\Omega}
\left[\log D_{metric,t,i}-\log(Z_{Pi3,t,i}+\epsilon)\right].
$$

其中 $Z_{Pi3,t,i}=(P^{L,Pi3}_{t,i})_z$，即相机系 local point 的 z-depth；若上游输出 ray distance，必须先转换到统一 z-depth 定义。

实现顺序：

1. 过滤 invalid、动态、遮挡、低置信像素；
2. 在 log 域求 weighted median；
3. 可选做一次 Huber IRLS 精化；
4. 对相邻重叠窗口的 `log s*` 做受限 median/EMA 平滑；
5. `s*` 全程 `stop-gradient`，学生不能参与求解。

同一个 $s^*$ 必须同时作用于：

```text
s* · local_points_Pi3
s* · world_points_Pi3
depth_Pi3 = (s* · local_points_Pi3)[..., z]
```

camera translation 不读取 Pi3X 的 direct-pose 输出，而由缩放后的 local/world point 通过 weighted SE(3) solver 自然产生。禁止逐帧独立 scale；否则窗口内的 baseline、point map 和求解平移会互相矛盾。

### 2.3 Gauge 处理

- relative transform 消除世界原点和朝向 gauge；
- `world_points_segment` 的窗口/segment 首帧固定为单位阵，首帧 local/world point 应在容差内重合；
- 尺度由 $s^*$ 固定后，只允许刚性 SE(3) gauge 对齐；
- 不允许再使用 Sim(3) 偷拟合一个自由尺度；
- 相邻窗口只能用重叠帧求一个 SE(3) 变换进行 gauge stitching，不能逐帧重新对齐；
- 主表 ATE 使用 SE(3) 对齐保留米制误差；Sim(3) 只用于诊断。

### 2.4 深度尺度与 GT pose 交叉校验

若有 GT pose，先在原始 Pi3 local/world point 上使用与部署相同的 weighted solver 得到 $t^{align}_{ij}$，再独立估计：

$$
s_{align}=\operatorname{median}_{(i,j)}
\frac{\|t^{GT}_{ij}\|}{\|t^{align}_{ij}\|+\epsilon}.
$$

将 $s_{align}$ 与 $s_{depth}$ 比较。冲突超过验证集阈值时：

- 关闭 metric translation magnitude KD；
- 保留点图形状、rotation、translation direction、baseline ratio 和 cycle 诊断；
- 将窗口标记为 `metric_valid=false` 或低 `scale_confidence`；
- 保存冲突原因供 teacher audit。

## 3. 总损失与阶段激活

核心总损失改为“先把双点图学对，再让固定求解器从点图产生位姿”：

$$
\begin{aligned}
\mathcal{L}_{total}={}&
\mathcal{L}_{depth}
+\lambda_l\mathcal{L}_{local\text{-}point}
+\lambda_w\mathcal{L}_{world\text{-}point}\\
&+\lambda_r\mathcal{L}_{pose\text{-}from\text{-}points}
+\lambda_g\mathcal{L}_{geometry}
+\lambda_m\mathcal{L}_{multi\text{-}span/cycle}\\
&+\lambda_q\mathcal{L}_{point\text{-}confidence}
+\mathcal{L}_{optional}.
\end{aligned}
$$

其中 `L_optional` 只包含独立消融通过后的 feature KD、train-only direct-pose auxiliary 或内部 token 正则；它们均不得写入正式 `T_frontend`。

| Loss | P0a | P0b 初期 | P0b 联合 | 目标学生 |
|---|:---:|:---:|:---:|:---:|
| `L_depth` | ✓ | ✓ | ✓ | ✓ |
| `L_local-point` | ✓ | ✓ | ✓ | ✓ |
| `L_world-point` | — | ✓ | ✓ | ✓ |
| `L_point-confidence` | 局部起步 | ✓ | ✓ | ✓ |
| `L_pose-from-points` | — | solver oracle 后启用 | ✓ | ✓ |
| `L_geometry/reprojection` | 局部可选 | — | ✓ | ✓ |
| `L_multi-span/cycle` | — | 小 span | ✓ | ✓ |
| `L_optional` | 消融后可选 | 默认关闭 | 可选 | 可删除 |

损失权重不在文档中硬编码为固定常数。推荐：

1. 每项先做单位和数量级归一；
2. 记录最后一个共享 block 的 `||g_depth/local||`、`||g_world/pose-from-points||` 与梯度余弦；
3. 先用 loss normalization/GradNorm 控制梯度量级；
4. 只有持续出现负余弦冲突时，才在共享主干使用 PCGrad/CAGrad；
5. task-specific heads 不做梯度投影；
6. feature KD 初始梯度贡献控制在主任务的约 5%–20%，再消融，而不是复制其他项目权重。

## 4. 深度与局部几何蒸馏

### 4.1 米制深度

GT、传感器或 `primary_metric` 分支：

$$
\mathcal{L}_{depth}^{metric}
=\mathcal{L}_{log\text{-}Huber}
+\alpha\mathcal{L}_{gradient}
+\beta\mathcal{L}_{normal}
+\gamma\mathcal{L}_{boundary}.
$$

- log-depth Huber 兼顾近处绝对误差和远处比例误差；
- gradient/boundary 防止蒸馏后过度平滑；
- normal cosine 传递表面朝向和平面结构；
- GT/标定传感器有效像素优先于伪标签；
- 对伪标签最高误差、教师分歧和无效边界区域截断或降权。

### 4.2 第二深度教师只教形状

第二教师必须去尺度化：

$$
\mathcal{L}_{shape}^{aux}
=\mathcal{L}_{SSI/ordinal}
+\alpha\mathcal{L}_{gradient}
+\beta\mathcal{L}_{normal}
+\gamma\mathcal{L}_{boundary}.
$$

它回答“哪里近、哪里远、表面怎样转折”，不能回答“是多少米”。禁止两个单目教师各自给等权 meter loss。

### 4.3 Metric local-point 监督（部署主输出）

已知 $K$ 时学生 point map 由深度反投影：

$$
P_s(u,v)=D_s(u,v)K^{-1}[u,v,1]^T.
$$

基础实现以 `base metric depth + K_network` 得到 pinhole-consistent base local point；可选小型 3D residual head，但必须受 ray consistency 和 residual magnitude 约束。residual 可以精修 XYZ，但正式 `depth_metric` 无条件重新取最终 `local_points_cam[...,2]`，因此始终只有一套米制答案。正式监督包括：

$$
\mathcal{L}_{local}
=\sum_i w_i\,\rho\left(
P^{L,S}_i-s^*P^{L,T}_i
\right),
$$

$$
\mathcal{L}_{depth\leftrightarrow local}
=\left\|D^S-(P^{L,S})_z\right\|_1,
$$

以及预测点方向与 $K^{-1}[u,v,1]^T$ 的 ray consistency。统一定义 `z_depth=local_points_cam[...,2]`、`range=||local_points_cam||₂`；任何 range 教师先转换到 local-Z。`local_points_cam` 是部署主输出，不能随 normal/reprojection 辅助头一起删除。

### 4.4 World-point 监督（P0b/部署主输出）

Pi3X teacher 的 `world_points` 先使用同一 $s^*$ 缩放，并固定窗口首帧 gauge。学生在同一像素网格输出 `world_points_segment`：

$$
\mathcal{L}_{world}
=\sum_i w_i\,\rho\left(
P^{W,S}_i-\bar P^{W,T}_i
\right).
$$

首帧增加 $P^{W,S}_0\approx P^{L,S}_0$；重叠窗口只允许一个 SE(3) gauge stitching。normal head 仍可作为训练辅助并在部署删除，但 local/world point heads 与 point confidence 必须保留。

## 5. 基于点图刚体对齐的位姿监督

### 5.1 因果 teacher window

- 正式窗口以目标帧 $t$ 结尾，只包含 `[t-W+1,...,t]`；
- 默认 $W=12$，训练随机裁 4–12 帧；
- stride `{1,2,4}` 和 frame-drop 必须保持时间顺序；
- 只监督末帧和 `(t-k,t)` 多跨度对；
- 若监督更早时刻，必须用其自身 prefix 重跑 teacher；
- 含未来帧的 full clip 标记为 `noncausal_upper_bound`，不得混入正式训练。

### 5.2 Weighted SE(3) solver 与 pose-from-points loss

对同像素有效点 $x_i=P^{L,S}_{t,i}$、$y_i=P^{W,S}_{t,i}$，使用 calibrated point confidence、valid/static/occlusion mask 与空间均匀采样权重求：

$$
\hat T^S_{w\leftarrow c,t}
=\arg\min_{R\in SO(3),t}
\sum_i\bar w_i\,\rho\left(\|Rx_i+t-y_i\|_2\right).
$$

初值使用 differentiable weighted Kabsch/SVD，并强制 $\det(R)=+1$。P0 同时审计 unweighted SVD、confidence-weighted SVD 与 2–3 次 Huber IRLS；T11 后每个训练/部署变体冻结唯一 `solver_id`，禁止逐帧挑选。当前首选 `weighted_se3_svd_huber_irls_v1`，只有 IRLS 无独立收益时才整体退回 weighted SVD。solver 只允许估计 SE(3)，不能逐帧估计自由 scale。相对位姿由 $\Delta\hat T_{i\leftarrow j}=\hat T_i^{-1}\hat T_j$ 派生。

所有旋转、平移和 2D 适配损失均施加在**点图注册得到的 pose**上，使梯度回传到 local/world point 和 confidence，而不是训练一个正式 direct-pose head。

旋转：

$$
\mathcal{L}_R=
\left\|\log\left((R^T_{ij})^T R^S_{ij}\right)\right\|_1.
$$

平移方向与米制幅值：

$$
\mathcal{L}_{dir}=1-\cos(t^S_{ij},t^T_{ij}),
$$

$$
\mathcal{L}_{translation}^{metric}
=\operatorname{Huber}(t^{align,S}_{ij}-t^{GT/align,T}_{ij}).
$$

地面机器人适配：

$$
\mathcal{L}_{2D}
=\operatorname{Huber}([\Delta x,\Delta z]^S-[\Delta x,\Delta z]^T)
+\alpha|\operatorname{wrap}(\Delta yaw^S-\Delta yaw^T)|.
$$

教师/GT 位移接近零时关闭 translation direction/magnitude，只保留 rotation，并加入纯旋转期间的 XY leakage 约束。若 $s_{depth}/s_{align}$ 冲突，则该窗口只保留 scale-free pose 诊断。

direct pose head 只能作为 `train_only` 辅助实验：它可提供表征正则或与注册结果比较，但不得写入 `T_frontend`、不得在 solver 失败时接管输出，正式导出必须删除。

### 5.3 Solver 诊断、退化与位姿不确定性

每帧 solver 必须报告：有效点数、空间覆盖率、weighted residual、阈值化/robust inlier ratio、交叉协方差奇异值、条件数和派生 covariance。近平面/窄视野/有效点过少/权重集中一角时标记 `weak/lost`，不得强行给出可信 pose。

训练 point confidence 可使用点残差的 heteroscedastic NLL，例如：

$$
\mathcal{L}_{point\text{-}nll}
=\exp(-u_i)\rho(\|\hat T P_i^L-P_i^W\|)+u_i.
$$

同时加入最小有效覆盖率/有效点数约束，防止所有 confidence 塌缩为零。frame pose covariance 由 solver 残差、有效点分布和 Hessian/奇异谱派生或校准，不能直接复用单个 point confidence。

## 6. 可选内部几何状态与辅助正则

world point 需要跨帧信息，因此 causal core 可以保留固定大小的 recurrent tensor、bounded KV 或少量 internal geometry token。它们的职责只有一个：让 `world_points_segment` 在统一 gauge 中更稳定。它们不是部署接口，也不需要被 LOGOPlanner/NavDP 或任何规划器消费。

若希望验证内部状态是否真的携带运动信息，可在训练期增加可删除的 probe：

```text
q(z_geo,i, z_geo,j) → ΔT_probe,i,j + uncertainty
```

约束如下：

1. probe 只使用 registration-derived/GT relative pose 作辅助监督；
2. probe 不得写入正式 `T_frontend`，也不得作为 solver 失败时的回退；
3. 若使用关系正则，只能从已缓存的 Pi3X local/world points 派生点间距离、Gram 或跨帧几何关系，不读取 Pi3X token/feature；
4. 比较 `无内部 token / recurrent tensor / bounded token` 时，必须固定 point heads、solver、数据和训练预算；
5. 判断收益只看 local/world point 质量、注册位姿、状态开销与长序列稳定性；
6. 无独立收益时删除 probe、projector 和 token，保留最简单的有界时序状态。

## 7. 多跨度、cycle 与联合几何

### 7.1 多跨度与组合

首轮 spans 使用 `{1,2,3}`，后续扩展到 `{1,2,4,8}`：

- 每帧先由预测的 local/world points 经同一个 weighted SE(3) solver 得到 `T_frontend_c2w`；
- 学生相邻注册位姿的 `ΔT` 连乘结果匹配长基线 GT/teacher point-registration relative pose；
- `ΔT_ik · ΔT_kj` 与 `ΔT_ij` 满足 composition/cycle；
- 长基线 loss 按时间跨度、point coverage 和 alignment confidence 归一；
- 低视差长跨度不强行施加 translation magnitude。

### 7.2 深度—点图—位姿闭环

正式闭环必须保持同像素对应关系：

```text
depth_metric + K_network
  → local_points_cam
  → 与 world_points_segment 做 confidence-weighted SE(3) registration
  → T_frontend_c2w
  → local points 变换到 segment world gauge
  → world-point / reprojection / cycle consistency
```

- `depth_metric` 必须无条件等于最终 `local_points_cam[...,2]`；base depth 只负责反投影初始化，若 residual 改变 Z，最终 depth 随之更新；
- local/world point 使用相同网格、相同单位、相同 valid/static mask 和逐像素一一对应，不先做 nearest-neighbor 再定义 pose；
- `T_frontend_c2w` 只来自该 registration，并用于把 local point 变换到 segment 世界系；
- 与统一尺度 Pi3X/GT world point 计算同索引 robust point loss，Chamfer 仅作无对应诊断；
- 加 point-to-image reprojection、normal 和静态背景跨帧 depth consistency；
- point confidence 必须通过 weighted-vs-unweighted solver 对照证明有效。

动态对象、遮挡和非刚体区域不满足静态重投影假设，必须使用 dynamic/instance/occlusion mask 或只在高置信静态背景计算。

### 7.3 重叠窗口 gauge 拼接

每个 causal teacher window 先固定首帧 gauge。相邻窗口通过重叠帧求一个共同 SE(3) 变换后再拼接；禁止对每帧独立重新对齐，也禁止在拼接时拟合额外 Sim(3) 尺度。重叠帧不足、求解病态或窗口尺度冲突时，该窗口标记为 `weak/lost`，只保留可审计的局部结果。

### 7.4 Permutation 只用于教师审计

Pi3X 可对同一 clip 的不同排列运行，输出还原时间索引后，用 local/world point dispersion 与派生 registration-pose dispersion 估计教师可靠性。学生的 causal state 必须感知时间顺序，禁止施加任意排列不变性；学生一致性只比较 order-preserving prefix、subset、stride 和 frame-drop。

## 8. 可选特征蒸馏

必须先有稳定的 `GT/primary output-only` 基线，再分别比较：

- `+ LingBot-Depth fused feature`：real sparse 与 pseudo depth 分开；
- `+ pure-RGB feature`：MoGe-2、LingBot-Vision、Depth Anything 系列；
- `+ Pi3X point-derived relation`：只从缓存的 local/world points 派生距离矩阵、Gram 与跨帧几何关系，不读取额外 Pi3X feature/token；
- `output-only`：不缓存大 token 的成本基线。

推荐关系式 feature KD：

$$
\mathcal{L}_{feature}
=\operatorname{SmoothL1}(\hat F_s,\hat F_t)
+\eta(1-\cos(\hat F_s,\hat F_t))
+\rho\mathcal{L}_{relation}.
$$

对 LingBot/MoGe/Depth Anything 等已单独登记的 `feature_privileged` 教师，学生 feature 先经过 LayerNorm + projector，教师 detach；`L_relation` 可匹配 token-pair cosine/Gram。Pi3X 例外：它的 relation 只能由 local/world points 派生，不能重新引入内部 token。也不同时蒸馏多个教师的早期 DINO token。

若删掉 feature KD 后性能不变，则删除 projector、token cache 和 feature teacher。feature KD 是可选增量，不是“做过蒸馏”的必要条件。

## 9. 可靠性与分歧门控

### 9.1 像素/点门控

$$
w_i=\mathbf{1}_{valid}\,c_i^{Pi3}
\exp\left[-\frac{|\log D_{metric,i}-\log(s^*Z_{Pi3,i})|}{\tau}\right].
$$

- 主尺度与 Pi3X local-point Z 一致、且 Pi3X confidence 高的像素权重最高；
- local/world 刚体对齐后仍有大残差的像素，在冻结的 `solver_id` 启用 Huber IRLS 时继续降权；
- GT 覆盖区域由 GT 决定谁可信；
- 没有 GT 时保存 teacher disagreement map，不硬平均。

学生 confidence 不能只复制 Pi3X confidence。应优先用 GT 变换后的 local/world point 残差生成 inlier/uncertainty 目标，并使用 heteroscedastic NLL、最小有效点数和最小空间覆盖率约束，防止模型通过把所有点权重降为零来“降低”注册损失。

### 9.2 窗口 registration 门控

$$
w_{align}=\operatorname{median}(c_{point}^{Pi3X})
\exp(-\lambda\sigma_{perm})\,c_{scale}.
$$

- `sigma_perm`：Pi3X 不同排列还原时间索引后的 point/registration-pose dispersion；
- `c_scale`：主尺度锚置信度；
- 低纹理/低视差、有效点集中一角或奇异谱退化：设置 `weak`，扩大窗口或沿用上一可靠状态；
- motion blur/动态窗口：降低全部 point-registration 权重；
- `s_depth/s_align` 冲突、anchor 过期：关闭 meter translation 监督，设置 `metric_valid=false`；
- 正式输出必须同时报告 effective points、spatial coverage、residual RMSE、inlier ratio、奇异值/条件数和 tracking status。

### 9.3 不确定性分离

分别校准：

- pixel-level `depth_confidence`；
- point-level `geometry_confidence`；
- frame/window-level、由 solver 残差与几何条件派生的 `pose_covariance`；
- anchor-level `scale_confidence`。

不得用同一个 confidence 同时控制所有 loss 和后端边权。

## 10. 教师数据生产与缓存

### 10.1 Clip 契约

- 默认 12 帧 causal window，训练随机裁 4–12；
- 同时采样小基线与中等基线 pair；
- stride `{1,2,4}`、frame-drop 保持时序；
- 所有教师共用相同 resize/crop/pad 和变换后的 $K$；
- 保存 RGB/depth/IMU 时间戳、动态/遮挡 mask 和可选 GT pose；
- full-clip 只标记为上界，不能与 causal 标签混用。

## 11. 课程式训练流程

| 阶段 | 冻结/训练 | 监督 | 通过标准 |
|---|---|---|---|
| S0 坐标/教师审计 | 教师冻结，不训练学生 | 坐标、K、尺度、gauge、solver oracle | 唯一主尺度确定；GT/teacher points 经统一 solver 正确 |
| S1 P0a depth + local point | Geo-Adapter + depth/local heads | GT/sensor/selected-primary、Pi3 local、gradient/normal | 原始米制 depth/local point 稳定优于旧基线 |
| S2 P0b world point | 加 2–4 层 causal/pair core 与 world head | Pi3X/GT world point、首帧 gauge | world point 跨帧稳定，local/world 同网格同单位 |
| S3 confidence + differentiable registration | 加 confidence head 与统一 solver | point residual/inlier、registration-derived pose | 学生 confidence 优于 uniform/teacher-confidence 基线且不塌缩 |
| S4 联合闭环 | 打开 pose-from-points、reprojection、multi-span/cycle、窗口拼接 | 共享尺度的 depth/local/world point | raw registration pose、漂移和窗口跳变改善 |
| S5 因果长序列 | 目标 bounded causal state | causal-prefix、退化/丢失恢复 | 状态 $O(1)$，无未来泄漏，weak/lost/reset 正确 |
| S6 部署验证 | 量化、调度和真机持续运行 | GT 主评；KD 教师已移除 | 点图尺度、solver pose、延迟、功耗与温控过门 |

P0a 和 P0b 可部分并行，但必须共享坐标、尺度和缓存契约。P0b 不必等待所有 feature KD 消融结束。

|---|---|---|

### 12.4 P0b point-map VO：V0–V10

|---|---|---|
| V0 | Pi3X local/world points + uniform-weight SE(3) SVD | 教师点图与 solver oracle 基线 |
| V1 | Pi3X points + Pi3 confidence-weighted SVD | 教师 confidence 是否真正改善配准 |
| V2 | 学生 local/world points + 固定 teacher confidence | 学生点图本身的可蒸馏性 |

## 13. 评估与验收闸门

### 13.1 深度和几何

- AbsRel、RMSE、δ1；主表禁止 median scaling；
- per-scene/camera scale bias、p95 scale error；
- `std(log s*)`、scale jump、temporal flicker；
- boundary F1、gradient error、normal angular error；
- local/world point median、RMSE、p90、有效覆盖率与同索引 world residual；
- weighted rigid residual、reprojection、跨帧 consistency；
- point-confidence ECE/AUSE/sparsification 与 coverage-error；
- 透明、反光、低纹理、细结构分桶。

### 13.2 Point-map registration 与位姿

- 正式 pose 全部来自预测 local/world points 与 confidence 的统一 solver；
- unweighted SVD、teacher-confidence SVD、student-confidence SVD 与 Huber-IRLS 公平对照；
- residual RMSE、inlier ratio、effective points、spatial coverage、SVD condition/degenerate rate、pose-invalid rate；
- RPE rotation/translation，跨度 1/5/10/20；
- `ATE-SE(3)` 作为米制主指标，`ATE-Sim(3)` 只诊断尺度；
- XY RMSE、Final XY、yaw RMSE、Final yaw、Tracked Rate；
- 每米/每 100m 漂移、终点漂移、回环闭合；
- 纯旋转 XY leakage、旋转后 jump、房间入口 X/Z jump；
- registration-derived pose covariance NLL/ECE/coverage、weak/lost 检出；
- raw `T_frontend` 与后端 `T_global` 分开报告。

### 13.3 几何应用和部署

- mask 内距离、物体 3D centroid p50/p90；
- fast low-resolution point maps、slow dense geometry refresh、weighted solver 与 scale-anchor 更新的分段 p50/p95；
- 峰值内存、序列长度曲线、INT8/FP16 精度、持续功耗和温控；
- RGB/depth/IMU 时间戳偏差、丢帧率、anchor `age_ms`。

### 13.4 硬门

主尺度教师冻结必须同时通过：无对齐深度、窗口尺度稳定、Pi3 点图尺度、teacher point-map solver 与学生部署态 point-map VO。

P0b 必须：

1. 所有正式 `T_frontend` 仅由 local/world points、confidence 和固定 SE(3) solver 产生；
2. V3/V4 至少优于 uniform 与 teacher-confidence 基线，且 confidence 不靠降低覆盖率作弊；
3. V7/V8 在 Habitat 和真机改善主要 metric RPE/ATE、XY/yaw/Tracked Rate；
4. 纯旋转 leakage、旋转后 jump、长走廊 drift 至少改善两类；
5. local/world point error、registration residual 与 pose error 具有合理相关性；
6. fast path 实时、状态有界，weak/lost/reset 与首帧 gauge 正确；
7. anchor 过期或点集退化时显式降级，不能静默输出伪米制 translation；
8. direct-pose/internal-token auxiliary 不得成为正式回退，无独立收益即删除。

若只改善同域 AbsRel，而 local/world point、注册稳定性、跨域与 VO 指标不改善，不能认定“蒸馏了深度与位姿能力”。

## 14. 实现顺序

```text
1. 固定坐标、K、preprocess、segment gauge、D0 与统一 SE(3) solver
2. 用合成/GT/teacher local-world points 完成 solver oracle 和退化单元测试
3. 生成 1k–2k clip 的 T0–T5 + T11 audit cache，选两个主尺度候选并冻结 solver 版本
4. 完成 D1/D2-A/B 与 C0/C1-A/B，冻结唯一 primary_metric
5. 批量生成 causal Pi3X local/world/confidence cache，完成 V0/V1
6. 完成 P0a local point 和 P0b world point，依次跑 V2/V3/V4
7. 加 V5/V6 的 depth-point 闭环、IRLS、mask 与退化门控
8. 加 V7/V8 的 multi-span/cycle、重投影和窗口 SE(3) 拼接
9. 完成 V9 causal state A/B；V10 auxiliary 仅按需验证且默认删除
10. 完成量化、分段 profile 和真机持续运行
```

训练 batch 伪代码：

```text
load causal clip + K_network + masks + teacher registry
select exactly one primary_metric
compute frozen window scale s* and scale confidence
scale Pi3 local/world points with the same s*
fix first-frame world gauge and build point/window gates

forward student causally
predict depth/local_points_cam/world_points_segment/point_confidence
enforce depth == local_points_cam[..., 2]
if P0b:
    T_frontend, diagnostics = differentiable_weighted_se3_solver(
        local_points_cam, world_points_segment,
        point_confidence * valid * static)
    compute local/world point KD and point-confidence targets
    compute pose-from-points, reprojection, multi-span and cycle losses
    reject/downweight degenerate windows from solver diagnostics
if feature ablation enabled:
    compute projected/relational feature KD

normalize losses and inspect shared gradients
backward/update trainable student modules
log raw frontend metrics, scale state and failure buckets
```

## 15. 风险与回退

| 风险 | 回退 |
|---|---|
| 主尺度错误污染 Pi3 点图与派生 translation | 用 GT/sensor/GT-alignment 校准；冲突窗口关闭米制幅值监督 |
| 多教师冲突 | 唯一 meter target；其他教师全部去尺度 |
| local/world 对应、坐标或单位错误 | 同网格同索引契约；合成刚体单元测试；首帧 gauge |
| 点集退化 | effective-points/coverage/condition/inlier 门控；输出 weak/lost |
| confidence 塌缩或装饰化 | NLL + 最小覆盖率；对比 unweighted/teacher/student confidence solver |
| 窗口 world gauge 跳变 | 只用重叠帧求一个 SE(3) 拼接；禁止逐帧/Sim(3) 重对齐 |
| solver 偷偷拟合自由尺度 | 正式求解器固定为 SE(3)；Sim(3) 只作诊断 |
| 非因果 teacher 泄漏 | causal prefix 重新生成；full clip 只报上界 |
| feature KD 负迁移 | 回退 output-only，删除 projector/cache |
| 内部 token 无收益 | 删除 token/probe，保留普通 bounded recurrent state |
| direct-pose auxiliary 掩盖失败 | 不写入 `T_frontend`、不作 fallback；导出删除 |
| 单帧学生信息上限 | 进入 P0b causal core，不继续堆单帧 loss |
| 动态场景重投影错误 | dynamic/occlusion mask，静态背景优先 |
| anchor 过期 | `age_ms/confidence/metric_valid` 显式降级 |
| 后端掩盖前端 | 分开报告 `T_frontend` 与 `T_global` |
| IMU 时间错位 | 协方差门控 factor；保留 RGB-only 回退 |
| loss 梯度冲突 | GradNorm；持续负余弦时 PCGrad/CAGrad |
| 标签成本失控 | 小审计、FP16 cache、只存必要 local/world point/confidence |
