## 0. 结论先行

不存在脱离目标域的“全局最优深度教师”。当前项目的冻结顺序是：

1. **可靠 GT / 标定传感器优先于任何学习模型**。Habitat 的 GT depth/pose、标定 RGB-D/LiDAR 的可靠像素直接监督，不先经过 learned teacher。
2. 无标签 RGB 且已知可靠内参时，以 **DA3Metric-Large 与 MoGe-2-normal** 竞争唯一 `primary_metric`：前者是纯米制尺度首候选，后者是 point/normal/mask 更完整的几何首候选。
3. **Metric3D v2** 做已知内参的独立尺度复核；未知或变化相机时，再加入 **UniDepthV2**。
4. 每个样本只能有一个米制尺度权威。第二名即使保留，也必须去尺度化，只监督 relative shape、normal、gradient 或 boundary。
5. **Pi3X 是多视点图教师，不直接作为 camera-pose teacher。** 本项目正式管线只读取其 `local_points`、`world_points` 与 `confidence`，通过 T11 冻结的唯一 confidence-weighted SE(3) solver 求解每帧 camera pose；当前首选候选为 SVD + Huber IRLS。Pi3X 点图的 Z、三维坐标和由对齐得到的平移必须共享由 GT/传感器/唯一主尺度教师得到的窗口尺度。
6. **LingBot-Depth 是可完全删除的条件式 RGB-D 特权教师**：只有真实/可信 sparse depth、传感器孔洞或 fused feature 消融确有收益时才保留。
7. 教师自身的 AbsRel 不能决定胜负。最终需要同时看：无对齐深度、窗口尺度抖动、`local_points`/`world_points` 质量、confidence 加权刚体对齐残差、point-map VO，以及由该教师训练出的部署态学生 point-map VO。
8. 正式 Pi3X 点图标签必须来自 causal prefix；camera pose 在标签侧同样由统一点图求解器派生。包含未来帧的 full clip 只允许作为非因果上界。
9. 模型权重许可是冻结硬门。研究可用不等于蒸馏出的学生可直接商用。

当前默认教师包：

```text
GT / calibrated sensor（有则最高优先级）
  或
DA3Metric-Large vs MoGe-2-normal 的目标域审计胜者（唯一米制尺度）

+ Pi3X（local_points + world_points + confidence；weighted SE(3) alignment 派生 camera pose，仅研究）

+ 可选辅助教师（必须独立消融）
  ├─ MoGe-2 / Depth Pro：去尺度 shape、normal、boundary
  ├─ Metric Video Depth Anything-Small：时序形状
  └─ LingBot-Depth：真实 sparse-depth completion / 特权 feature
```

## 1. 当前输入条件与本文交付物

### 1.1 当前项目条件

- 相机内参 $K$ 可标定；所有 resize/crop/pad 必须同步产生 `K_network`。
- Habitat 可提供无噪声 GT depth 和 GT pose；真机可采标定 RGB-D。
- 最终部署学生仍以 RGB 为主输入，因果在线运行，状态有界。
- 深度不仅用于逐像素评测，还用于物体 3D 定位和位姿平移尺度锚。
- Pi3 系列当前用于前馈 point-map VO；其尺度和 gauge 不能不经处理直接监督学生。
- 正式数据管线只读取 Pi3X 的 `local_points`、`world_points` 与 `confidence`，并通过统一的加权刚体对齐求 camera pose；项目内实验只代表这条 point-map VO 工程链路，不作为公开 benchmark 结论。

### 1.2 教师选型最终必须产出

1. 一份版本化 `teacher registry`；
2. 每种数据条件下唯一的 `primary_metric`；
3. Pi3X 是否启用、使用哪个 checkpoint、local/world point 定义、confidence 标定、加权刚体对齐版本、许可边界和 causal 标签配置；
4. 辅助教师及其严格角色；
5. 被否决教师及否决原因；
6. 伪标签预处理、尺度校准、置信度和缓存配置；
7. 教师冻结指标、回退策略和审计数据版本。

## 2. 教师角色注册与不可违反的红线

模型名不等于监督角色。每个教师进入数据管线前必须登记为下列一种或多种受限角色：

| 角色 | 权限 | 典型来源 | 禁止行为 |
|---|---|---|---|
| `primary_metric` | **唯一允许定义米制深度和 Pi3 窗口尺度** | GT、标定 RGB-D/LiDAR、目标域审计胜出的单目 metric 模型 | 同一样本同时存在两个 meter target |
| `relative_shape` | relative depth、ordinal、gradient、normal、boundary | MoGe-2、Depth Pro、视频深度模型、第二名单目教师 | 覆盖或重新缩放 `primary_metric` |
| `pointmap_vo` | `local_points`、`world_points`、逐点 confidence，以及由它们确定性派生的 camera pose | Pi3X | 越过统一点图求解器读取未登记输出；把 approximate metric 当尺度真值；对退化点集强行求位姿 |
| `feature_privileged` | 训练期 feature/relation/query 表示 | LingBot-Depth、LingBot-Vision、MoGe-2 | 未经消融就成为必选项；覆盖输出监督 |
| `validator` | 复核尺度、内参或困难分桶 | Metric3D v2、UniDepthV2、MapAnything | 与主教师等权平均 |

尺度来源优先级固定为：

```text
metric depth / pose GT
> 标定 RGB-D / LiDAR 的可靠有效像素
> 经目标域 GT 子集校准的单目 metric teacher
> 未校准单目 metric teacher
> Pi3X approximate metric
> 无尺度：metric_valid=false
```

低优先级来源不得覆盖高优先级来源。一个模型可以提供多种输出，但不能因此自动获得多种权力。例如 MoGe-2 可以同时输出 depth、point、normal，却仍需通过审计才能成为 `primary_metric`；Pi3X 即使还能产生其他输出，本项目也只登记其 `local_points`、`world_points` 与 `confidence` 为 `pointmap_vo` 数据源。

### 2.1 教师选择标准

1. 目标域无对齐米制准确性：AbsRel、RMSE、per-scene scale bias、p95 scale error；
2. 对 point-map VO 的影响：local/world point 误差、加权刚体对齐残差、退化率、`std(log s*)`、scale jump、RPE-t/RPE-r 与 ATE；
3. 输入条件是否匹配：RGB、$K$/FOV、sparse/raw depth；
4. 点图信号是否完整：local/world 坐标定义、有效覆盖率、对应关系、几何边界及 confidence；
5. 跨帧稳定性：point flicker、world-point 一致性、相邻窗口位姿和尺度跳变；
6. confidence 能否在目标域校准；
7. 学生能否吸收：metric local point、world point 与 confidence KD 是否改善点图求姿；feature KD 是否真有额外增益；
8. checkpoint、预处理和代码能否稳定复现；
9. 许可是否允许目标使用和发布；
10. 离线吞吐、显存、缓存量和全量标签周期。

## 4. 条件式选择树

```text
是否有可靠目标域米制 depth 或 pose GT？
├─ 有
│  ├─ dense GT / 标定 RGB-D/LiDAR 有效像素
│  │  ├─ GT/sensor 直接作为 primary_metric
│  │  └─ learned teacher 只补无效区、边界、normal 或无标签样本
│  └─ 只有 sparse/noisy depth
│     ├─ 孔洞、玻璃、反光、低纹理是主要失败源
│     │  └─ 审计 LingBot-Depth / MapAnything completion
│     └─ 否
│        └─ sparse GT + RGB-only metric teacher
└─ 没有
   ├─ K/focal 可靠
   │  └─ DA3Metric-Large vs MoGe-2-normal；Metric3D v2 复核
   ├─ K/focal 不可靠或相机变化大
   │  └─ UniDepthV2 vs MoGe-2；内参 confidence 进入门控
   └─ 所有候选绝对尺度都不可靠
      └─ metric_valid=false：只教 relative depth/normal、去尺度 local/world
         point 结构；对齐结果只保留 rotation 与 translation direction

尺度教师确定后，再决定 feature teacher：
├─ completion/fused feature 稳定改善 local/world point 或 point-map VO → 保留
├─ 只有边界/形状问题 → 比较结构 loss 与纯 RGB feature
└─ output KD 已足够 → 不增加 feature teacher
```

### 4.1 当前项目首轮排序

1. GT/标定传感器有效像素直接监督；
2. DA3Metric-Large 与 MoGe-2-normal 在同一目标域、同一 `K_network` 和同一有效区 A/B；
3. Metric3D v2 在相同 $K$ 下做独立复核；
4. 只有未知/变化相机或研究许可允许时加入 UniDepthV2；
5. MetricAnything 只做 1k–2k clip 小审计，复现通过前不批量缓存；
6. 最终只允许一个 `primary_metric`；
7. 教师直接指标筛出前两名后，必须比较它们对 Pi3 点图尺度、confidence 加权刚体对齐和训练后学生 point-map VO 的影响。

DA3Metric-Large 的米制换算依赖网络输入坐标系的 focal。若 resize/crop/pad 后仍误用原图 focal，预处理缩放会被直接写入 depth、Pi3 点图以及刚体对齐派生的 translation。教师审计前必须用合成平面、已知深度与已知 $K$ 做单元测试，确保 `K_original → K_network` 正确。

### 4.2 LingBot-Depth 何时保留

仅在以下条件同时成立时进入正式候选：

- 有真实 raw/sparse depth、SfM 点或可信孔洞模式；
- 玻璃、反光、低纹理或深度缺失是主要失败源；
- 教师只在训练期使用，学生部署仍为 RGB-only；
- real-sparse 与 pseudo-depth 两条实验完全分开；
- completion 或 fused-feature KD 在相同预算下改善深度、local/world point、刚体对齐成功率或 point-map VO。

以下情况直接删除：

- 只有 RGB，必须由另一单目模型生成其全部 depth 输入；
- Habitat GT 或标定传感器有效区已足够；
- 预算只允许一个深度教师；
- 主要缺口是时序一致性、RGB-only point map 或刚体对齐稳定性；
- feature KD 相对 output-only 未超过随机波动和额外成本。

### 4.3 Pi3X 的职责边界：点图教师，不是直接位姿教师

本项目只消费 Pi3X 的三类输出：

1. 每帧相机坐标系 `local_points`；
2. 同一 segment/window 公共坐标系 `world_points`；
3. 与点一一对应的 `confidence`。

正式管线不读取 Pi3X 的其他位姿或内部表示。camera pose 只由 local/world 同索引点对进行置信度加权刚体对齐得到：

$$
\hat T_{w\leftarrow c,t}
=\arg\min_{R\in SO(3),\,\mathbf t}
\sum_{i\in\Omega_t}w_{t,i}\,
\rho\!\left(
\left\|R(s^*p^L_{t,i})+\mathbf t-s^*p^W_{t,i}\right\|_2
\right).
$$

统一求解器以 confidence-weighted SE(3) SVD/Procrustes 为初值；当前首选候选再用 Huber IRLS 对三维残差重加权，最终版本由 T11 冻结。$\Omega_t$ 仅包含 local/world 双方有效、静态、非遮挡且 confidence 通过阈值的点。相对位姿由派生的绝对位姿计算：

$$
\Delta T_{c_i\leftarrow c_j}
=\hat T^{-1}_{w\leftarrow c,i}\hat T_{w\leftarrow c,j}.
$$

| 正式路径 | 输入 | 派生输出 | 用途 |
|---|---|---|---|
| **point-map VO** | `local_points` + `world_points` + `confidence` | `T_frontend_c2w`、`delta_T_prev_cur`、alignment residual、inlier ratio、pose covariance/status | VO 积分、滑动窗口、故障检测和评测 |

必须同时保留 unweighted SVD、confidence-weighted SVD 与 confidence-weighted SVD + Huber IRLS 三个求解器对照，以证明 confidence 和鲁棒重加权确实改善位姿。点集近平面、空间分布过窄、有效点不足或互协方差病态时，应报告 `tracking_status=weak/lost`，不得强行输出可信 camera pose。Pi3X 的 approximate metric 不得覆盖 GT、标定传感器或经目标域校准的 `primary_metric`。

## 5. 推荐教师包

### 包 A：最小默认包

```text
GT/sensor（有则直接作为尺度）
或 Selected Primary Metric（DA3 vs MoGe 审计胜者）
+ Pi3X（local/world point + confidence → weighted SE(3) SVD/IRLS → camera pose，研究阶段）
```

### 包 B：几何细节增强

```text
Selected Primary Metric（唯一尺度）
+ MoGe-2-normal / Depth Pro（去尺度 depth-shape / normal / boundary）
+ Pi3X（local/world point + confidence → weighted SE(3) SVD/IRLS）
```

### 包 C：真实稀疏深度或传感器孔洞

```text
GT / calibrated sensor valid pixels
+ LingBot-Depth（真实 sparse depth）
+ 可选 MapAnything completion 上界
+ Pi3X（local/world point + confidence）
```

### 包 D：视频时序增强

```text
Selected Primary Metric（关键帧尺度）
+ Metric Video Depth Anything-Small（去尺度 temporal shape）
+ Pi3X（local/world point + confidence）
```

### 包 E：许可敏感的 RGB-only 路线

```text
DA3Metric-Large 或 MoGe-2-normal
+ 可选 LingBot-Vision / LingBot-Depth
+ MapAnything-Apache 小规模复核
+ 获得明确授权的 point-map teacher 或自训几何教师
```

Pi3X、CUT3R、DUSt3R/MASt3R 的公开权重含非商业限制。计划商业发布时必须取得书面许可或替换教师，不能假定蒸馏后的学生天然摆脱原权重限制。

## 6. 目标域教师审计协议

### 6.1 审计数据

- 1k–2k 个 scene-disjoint causal clips，默认 12 帧并随机裁成 4–12 帧；
- ScanNet/ScanNet++ 到 ARKitScenes、NYUv2、7-Scenes、TUM 的 cross-dataset split；
- Habitat 与真实机器人目标相机 split；
- 透明/反光、低纹理、细结构、大运动、纯旋转分桶；
- 不同 focal/FOV、分辨率、相机高度分桶；
- 长序列、窗口重叠、revisit 与回环分桶；
- 所有教师使用相同图像、有效区、resize/crop/pad 和 `K_network`；
- local/world point 使用相同像素索引、valid mask、坐标方向、单位和深度定义；
- 专门包含纯旋转、近平面、窄视野、低纹理、有效点过少和空间分布单一等刚体对齐退化窗口；
- 同一窗口固定比较 unweighted SVD、confidence-weighted SVD 与 confidence-weighted SVD + Huber IRLS。

### 6.2 T0–T11 直接审计矩阵

| ID | 设置 | 角色 | 必须回答的问题 |
|---|---|---|---|
| T0 | GT / calibrated sensor | 上界 | 覆盖率、噪声和孔洞在哪里 |
| T1 | DA3Metric-Large | metric A | 已知 focal 下 scale bias/jitter 是否最小 |
| T2 | MoGe-2 ViT-L-normal | metric/geometry B | local point、normal 和有效区是否改善 Pi3 点图尺度与刚体对齐 |
| T3 | Metric3D v2 | 已知 $K$ 复核 | Canonical Camera 路线是否更稳 |
| T4 | UniDepthV2-Large | 跨相机复核 | 未知/变化相机是否更稳，confidence 是否需重校准 |
| T5 | MetricAnything PointMap | 观察项 | checkpoint/预处理能否复现并超过 T1/T2 |
| T6 | Metric Video Depth Anything-Small | temporal shape | flicker 是否下降，窗口尺度是否变差 |
| T7 | LingBot-Depth + real sparse | RGB-D completion | 困难材质/传感器孔洞是否有独特收益 |
| T8 | LingBot-Depth + pseudo depth，feature-only | privileged feature | 二次加工是否提供新信息 |
| T9 | Depth Pro | boundary | 细结构是否改善下游物体 3D 定位 |
| T10 | MapAnything-Apache | joint upper bound | 是否能提供独立的 local/world point 或尺度上界，复核 Pi3 点图错误 |
| T11 | Pi3X alignment solver audit | point-map VO | unweighted、confidence-weighted 与 Huber-IRLS 的残差、退化率和 RPE 差异 |

T1–T5 先小规模运行，只有前两名进入学生 A/B 与全量缓存。T7 和 T8 必须分开汇报。

### 6.3 尺度与 gauge 审计

以 `local_points` 的 Z 分量作为 Pi3X 深度：

$$
Z_{Pi3,t,i}=(p^L_{t,i})_z.
$$

统一术语：`z_depth = local_points[...,2]`，`range = ||local_points||₂`。任何只提供 range 的教师都必须先按相机射线转换为 local-Z，才能进入米制尺度比较。

在窗口可信重叠区域求唯一尺度：

$$
\log s^*=\operatorname{weighted\ median}_{(t,i)\in\Omega}
\left[\log D_{metric,t,i}-\log(Z_{Pi3,t,i}+\epsilon)\right].
$$

同一个 $s^*$ 必须同时缩放 `local_points` 与 `world_points`。camera translation 不读取模型输出，而由缩放后点图的 weighted SE(3) SVD/IRLS 自然产生。禁止逐帧独立缩放；禁止在已固定尺度后再用 Sim(3) 额外拟合一个自由尺度。尺度计算必须 `stop-gradient`。

每个窗口先把首帧规定为 `T=I`，并把整窗 world points 一次性归一到该首帧 gauge。相邻窗口只能用所有可靠重叠帧共同估计一个 SE(3) `overlap_T_se3` 再整体拼接；禁止逐帧分别对齐。必须缓存该拼接的 residual、inlier ratio 和 `ok/weak/lost` 状态。

刚体对齐的初始点权重为：

$$
w^{(0)}_{t,i}=\mathbf 1_{valid}\,c^{Pi3X}_{t,i}
\exp\left(
-\frac{\left|\log D_{metric,t,i}-\log(s^*Z_{Pi3,t,i})\right|}{\tau_d}
\right).
$$

先用该权重完成一次 SE(3) weighted SVD，再根据三维残差运行 Huber IRLS。每帧必须记录 local-to-world 加权残差：

$$
E_{LW,t}=\sqrt{
\frac{\sum_{i\in\Omega_t}w_{t,i}
\left\|\hat R_t(s^*p^L_{t,i})+\hat{\mathbf t}_t-s^*p^W_{t,i}\right\|_2^2}
{\sum_{i\in\Omega_t}w_{t,i}+\epsilon}}
.
$$

同时记录有效点比例、各 solver 的 inlier ratio、点集协方差特征值、互协方差条件数、残差 p50/p95 和 confidence–error risk-coverage。首轮固定比较：

1. unweighted SE(3) SVD；
2. confidence-weighted SE(3) SVD；
3. confidence-weighted SE(3) SVD + Huber IRLS。

只有第 2/3 项相对第 1 项稳定改善对齐残差、tracking rate 和轨迹误差，`confidence` 才能被冻结为正式权重。

P0 审计期间三种 solver 均运行；T11 结束后，每个训练/部署变体必须冻结唯一 `solver_id`，禁止按帧挑选最有利的求解器。当前首选候选为 `weighted_se3_svd_huber_irls_v1`，只有审计未证明 IRLS 有增益时才退回固定的 weighted SVD。

若有 GT pose，先在未施加 $s_{depth}$ 的原始 Pi3X 点图上完成同一加权刚体对齐，得到无尺度平移 $\tilde t^{align}$，再独立估计：

$$
s_{align}=\operatorname{median}_{(i,j)}
\frac{\|t^{GT}_{ij}\|}{\|\tilde t^{align}_{ij}\|+\epsilon}.
$$

当 $s_{align}$ 与 $s_{depth}$ 冲突超过验证集阈值时，该窗口不得输出米制 camera translation，只保留由点图对齐得到的 rotation、translation direction 和无尺度轨迹诊断，并设置 `metric_valid=false`。

窗口对齐可靠性权重：

$$
w_{align}=\operatorname{median}(c_{point}^{Pi3X})
\exp(-\lambda\sigma_{perm}^{align})
\exp(-\mu E_{LW})\,c_{scale}.
$$

其中 $\sigma_{perm}^{align}$ 来自同一窗口不同输入排列后，以同一求解器从点图派生的 pose dispersion；`c_scale` 表示尺度锚可信度。它只用于评价点图与对齐稳定性，不引入任何直接位姿输出。

### 6.4 冻结指标

教师必须同时过五道门：

1. **目标域无对齐深度**：主表不做 median scaling，统计 AbsRel/RMSE/δ1、scale bias 和 p95 error；
2. **local point 质量**：相机系 point error、Z-depth error、有效覆盖率、边界保持和局部平面误差；
3. **world point 质量**：固定首帧 SE(3) gauge 后的 world-point error、跨帧一致性、`E_LW`、`std(log s*)` 与 scale jump；
4. **confidence 加权刚体对齐**：相对 unweighted SVD，weighted SVD/IRLS 必须改善 residual、inlier ratio、有效跟踪率、RPE-r/RPE-t、ATE-SE(3)、XY/yaw、纯旋转 translation leakage 和窗口跳变；
5. **学生部署态 point-map VO**：使用该教师训练出的同容量学生输出 local/world point 与 confidence，经同一求解器得到的 raw `T_frontend`、物体 3D 定位和 tracking rate 不退化。

只在教师自身 depth benchmark 胜出，却使 local/world point 质量、加权对齐稳定性或部署态 point-map VO 变差的候选不得冻结。

## 8. 风险与回退

| 风险 | 识别信号 | 回退 |
|---|---|---|
| LingBot 输入模态错配 | pseudo-depth feature 无独立收益 | 分开 real/pseudo；不通过即删除 |
| 主尺度偏差 | 点图对齐派生的平移同比例偏移、窗口跳变 | GT/sensor/GT-pose 校准；冲突窗口设置 `metric_valid=false` |
| 多个米制教师冲突 | depth 折中但 VO 尺度不稳 | 唯一 `primary_metric`；其余去尺度 |
| Pi3 点图 gauge/尺度错误 | local/world point 系统性漂移 | 统一窗口尺度；首帧固定 SE(3) gauge；只做 local/world 刚体对齐 |
| local/world 对应或坐标定义错误 | 对齐残差巨大、旋转/平移方向异常 | 合成刚体变换单元测试；记录坐标轴、单位、点索引和变换方向 |
| 点集退化 | 近平面、窄视野或少量点导致 pose 跳变 | 条件数/inlier 门控；标记 weak/lost；扩大窗口或沿用上一可靠状态 |
| confidence 无效或失准 | weighted SVD 不优于 unweighted SVD | 做 risk-coverage 校准；不通过时禁用 confidence 权重 |
| 非因果泄漏 | 离线指标好、逐帧部署崩 | 正式标签仅 causal prefix；full clip 只作上界 |
| 教师错误相关 | 多教师一致但都错 | 目标域 GT 分桶校准；保留困难材质/FOV 审计 |
| feature KD 负迁移 | feature loss 降、任务不升 | 回退 output-only，删除 projector/cache |
| 伪标签成本失控 | 标签周期和存储超预算 | 先审计再缓存；FP16；只存必要 local/world point 与 confidence |
| 许可不满足 | 研究模型无法用于发布 | 替换明确授权教师、自训教师或取得书面许可 |
