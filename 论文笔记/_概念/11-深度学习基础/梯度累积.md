# 梯度累积

## 定义
将多个小 batch 的梯度累加后再做一次参数更新，从而在显存受限时模拟大 batch 训练。

## 核心要点
1. 用时间换显存，在消费级 GPU 上模拟大 batch
2. 与 [[Batch Normalization]] 冲突（BN 依赖 batch 统计），常需改用 [[Layer Normalization]]
3. [[RF-DETR]] 用 LayerNorm 替 BatchNorm 以支持梯度累积训练

## 代表工作
- [[RF-DETR]]: 借梯度累积在消费级 GPU 训练
