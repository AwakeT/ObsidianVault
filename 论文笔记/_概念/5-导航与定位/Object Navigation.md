# Object Navigation

## 定义
在未知环境中根据语义目标名称（如cup）导航至目标物体附近的任务。

## 数学形式
N/A

## 核心要点
1. 标准评估指标为 SR 和 SPL
2. 开放词汇 ObjectNav 不限制目标类别
3. 终身 ObjectNav 要求跨 episode 记忆
